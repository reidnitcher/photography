# Photos

Drop your image files (`.jpg`, `.jpeg`, `.png`, `.webp`) directly into this
folder. The gallery on the homepage picks them up automatically — no code
changes needed.

Photos are sorted by filename, so prefix them with numbers if you want a
specific order, e.g. `01-mountains.jpg`, `02-portrait.jpg`.

Tips:
- Keep individual files under a few MB — resize/export large RAW-derived
  files to something web-sized (long edge ~2000-2500px is plenty).
- This `README.md` file is ignored by the gallery; only image files show up.
